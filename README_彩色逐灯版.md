# Rina Board Controller（彩色逐灯版）

本工程以你提供的 `RinaBoardController` Compose 模板为基础修改，保留原来的主页、设备页、设置页、SU-03T 控制、电量显示、表情控制和横屏绘画布局。

新增功能：

- 临时绘画支持 308 颗灯珠逐颗独立 RGB 颜色。
- R/G/B 三个滑块由手机直接选择当前画笔颜色。
- 每颗灯珠保存自己的颜色，换画笔颜色不会修改已经画好的灯珠。
- 橡皮擦只把经过的灯珠改成黑色（熄灭）。
- 使用 `PB -> PC<start>,<RRGGBB...> -> PF` 分块协议发送整帧，默认每包 64 颗，避免 HTTP 请求过长。
- SU-03T 电源说明更新为 GPIO42。

与 ESP32-S3 固件对应的彩色协议：

```text
PB
PC0,FF69B4FF69B4000000...
PC64,...
PC128,...
PC192,...
PC256,...
PF
```

其中每颗灯珠占 6 个十六进制字符 `RRGGBB`，编号范围 0~307。
